# ArtEcho — платформа для отзывов на произведения


[![Python](https://img.shields.io/badge/Python-3.9-blue)](https://python.org)
[![Django](https://img.shields.io/badge/Django-3.2-green)](https://djangoproject.com)
[![DRF](https://img.shields.io/badge/DRF-3.12-red)](https://www.django-rest-framework.org)


**ArtEcho** — это платформа, где пользователи могут публиковать отзывы и оценки на произведения разных категорий: фильмы, книги, музыку и другие медиа. Проект включает:

## Структура проекта

### Основные приложения

#### 1. `reviews` - ядро функциональности
- **Модели**:
  - Произведения (Title)
  - Отзывы (Review)
  - Комментарии (Comment)
  - Категории (Category)
  - Жанры (Genre)
- **Шаблоны**:
  - Базовые страницы интерфейса
  - Формы создания/редактирования контента
- **Логика**:
  - Расчет средних рейтингов произведений

#### 2. `users` - управление пользователями
- Кастомная модель `User` с полями:
  ```python
  bio = models.TextField()
  role = models.CharField(choices=ROLES)
```
Функционал:
- Регистрация через email
- Смена пароля
- Профиль пользователя

#### 3. `api` - REST API
Документация API:

Интерактивная документация Swagger UI:
http://127.0.0.1:8000/swagger/

Альтернативная версия в Redoc:
http://127.0.0.1:8000/redoc/

- JWT-токены (/auth/token/)
- Система ролей (user/moderator/admin/superuser)

Эндпоинты:

- `GET /api/v1/titles/` - список произведений
- `POST /api/v1/titles/{id}/reviews/` - добавление отзыва
- `PATCH /api/v1/users/me/` - обновление профиля

#### 4. `custom_commands` - управление данными.
Приложение предоставляет набор кастомных команд для администрирования данных через Django management commands.

Основные возможности:

- Импорт данных – загрузка в БД из CSV/JSON файлов
- Очистка таблиц – удаление записей из таблицы или списка таблиц

## Особенности интерфейса

### Кастомные селекты

#### Механизм работы


- Нативные `<select>` элементы остаются в DOM, но визуально скрываются через CSS
- JavaScript динамически создает кастомные элементы интерфейса (div-структуру)
- Все изменения синхронизируются между кастомным интерфейсом и оригинальным select

## Установка

1. Клонирование проекта

Клонируйте репозиторий на ваш компьютер:

#### Windows/macOS/Linux:
```bash
git clone git@github.com:HermannRorshach/api_yamdb.git
```

### 2. Установка виртуального окружения с Python 3.10

#### Windows:
```bash
py -3.10 -m venv venv
```
#### macOS/Linux:
```bash
`python3.10 -m venv venv`
```

### 3. Активировать виртуальное окружение

#### Windows:

```python
source venv/Scripts/activate
```
#### macOS/Linux:
```bash
source venv/bin/activate
```

### 4. Установка зависимостей

После активации виртуального окружения установите все необходимые зависимости с помощью pip:
#### Windows/macOS/Linux:
```bash
pip install -r requirements.txt
```
