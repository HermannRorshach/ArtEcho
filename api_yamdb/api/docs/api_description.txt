<div class="api-docs">
  <p>Запросы к API начинаются с <code>/api/v1/</code></p>
  
  <h2>Описание</h2>
  <p>Проект <strong>ArtEcho</strong> собирает отзывы пользователей на различные произведения.</p>
  
  <h2>Алгоритм регистрации пользователей</h2>
  <ol>
    <li>Пользователь отправляет POST-запрос на добавление нового пользователя с параметрами <code>email</code> и <code>username</code> на эндпоинт <code>/api/v1/auth/signup/</code>.</li>
    <li><strong>ArtEcho</strong> отправляет письмо с кодом подтверждения (<code>confirmation_code</code>) на адрес <code>email</code>.</li>
    <li>Пользователь отправляет POST-запрос с параметрами <code>username</code> и <code>confirmation_code</code> на эндпоинт <code>/api/v1/auth/token/</code>, в ответе на запрос ему приходит <code>token</code> (JWT-токен).</li>
    <li>При желании пользователь отправляет PATCH-запрос на эндпоинт <code>/api/v1/users/me/</code> и заполняет поля в своём профайле (описание полей — в документации).</li>
  </ol>
  
  <h2>Пользовательские роли</h2>
  <ul>
    <li><strong>Аноним</strong> — может просматривать описания произведений, читать отзывы и комментарии.</li>
    <li><strong>Аутентифицированный пользователь</strong> (<code>user</code>) — может, как и <strong>Аноним</strong>, читать всё, дополнительно он может публиковать отзывы и ставить оценку произведениям (фильмам/книгам/песенкам), может комментировать чужие отзывы; может редактировать и удалять <strong>свои</strong> отзывы и комментарии. Эта роль присваивается по умолчанию каждому новому пользователю.</li>
    <li><strong>Модератор</strong> (<code>moderator</code>) — те же права, что и у <strong>Аутентифицированного пользователя</strong> плюс право удалять <strong>любые</strong> отзывы и комментарии.</li>
    <li><strong>Администратор</strong> (<code>admin</code>) — полные права на управление всем контентом проекта. Может создавать и удалять произведения, категории и жанры. Может назначать роли пользователям.</li>
    <li><strong>Суперюзер Django</strong> — обладает правами администратора (<code>admin</code>).</li>
  </ul>
